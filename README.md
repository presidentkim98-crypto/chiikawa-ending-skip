# 먼작귀 엔딩 스킵 (비공식)

유튜브 **애니박스 먼작귀 전편공개 재생목록**에서 본편이 끝나고 엔딩곡이 시작되면 자동으로 다음 회차로 넘겨 주는 크롬 확장 프로그램입니다.
운동하거나 다른 일을 하면서 틀어둘 때 매번 다음 화를 누르지 않아도 됩니다.

> 개인이 만든 비공식 도구이며 애니박스, 원작자, 유튜브와 관련이 없습니다.

## 설치 방법 (PC 크롬 / 엣지 / 웨일)
1. 이 페이지 위쪽의 초록색 **Code** 버튼 → **Download ZIP** 으로 내려받고 압축을 풉니다.
2. 주소창에 `chrome://extensions` 입력 (엣지는 `edge://extensions`, 웨일은 `whale://extensions`)
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더 중 `manifest.json`이 들어 있는 폴더를 선택합니다.
5. **이미 열려 있던 유튜브 탭은 새로고침(F5)** 해 주세요.

압축 푼 폴더를 지우거나 옮기면 확장 프로그램이 동작하지 않으니 그대로 두세요.

## 사용법
재생목록에서 영상을 열면 플레이어 왼쪽 위에 상태가 표시됩니다.

| 표시 | 뜻 |
|---|---|
| 🟢 `엔딩 스킵: 1:01에 다음 화로` | 정상 동작 중 |
| ⚫ `재생목록이 아님` | 재생목록 링크(주소에 `&list=` 포함)로 열어 주세요 |
| ⚫ `광고 중` | 광고가 끝나면 초록색으로 바뀝니다 |
| ⚫ `꺼져 있음` | 확장 아이콘을 눌러 '켜기'를 체크하세요 |
| 아무 표시 없음 | 유튜브 탭을 새로고침하세요 |

## 설정 (툴바의 확장 아이콘 클릭)
- **끝에서 몇 초 남았을 때 넘기기**: 기본 29초. 1:31 길이 회차에서 엔딩이 시작되는 1:01에 넘어갑니다.
  노래가 살짝 들리면 숫자를 올리고, 본편 끝이 잘리면 내리세요.
- **먼작귀 영상에서만**: 켜 두면 제목에 '먼작귀'가 들어간 영상(또는 애니박스 전편공개 재생목록)에서만 동작합니다.
- 3분이 넘는 영상과 광고에는 동작하지 않습니다.
